PhishLens

Plain-English verdicts for pasted email headers and links.

This page is a static showcase, not a live analyzer. Both emails below are made-up samples, and their verdicts were computed ahead of time by the PhishLens command-line tool. Every link and domain is defanged (hxxps://, [.]), so nothing here is clickable except the project link. To analyze your own email, run PhishLens locally: it works offline and stores nothing.

Source code: github.com/battlettt/phishlens

LIKELY PHISHING

This email shows strong signs of phishing. It is very likely not from who it claims to be, or it tries to send you somewhere dangerous.

Authentication, checked separately

SPFFAILThe sending server is NOT on the list of servers allowed to send mail for mailer-notify[.]top.
DKIMNONEThe message is not digitally signed.
DMARCNONEpaypa1-secure[.]com publishes no DMARC policy, so the From address is not protected against spoofing.

Why

  1. HIGH The sender's name claims to be PayPal, but the address is not PayPal's
    The name says 'PayPal Security' but the address is service@paypa1-secure[.]com. PayPal sends from its own domain (such as paypal[.]com), not this one.
  2. HIGH The From domain imitates PayPal
    'paypa1-secure[.]com' is spelled to look like PayPal's real domain (paypal[.]com or paypal[.]me), but it is a different domain: paypa1-secure[.]com.
  3. HIGH A link in the message is dangerous: hxxp://198[.]51[.]100[.]23:8080/paypal[.]com/webscr/login[.]php
    The link text shows one site but the link goes to another. You see 'hxxps://www[.]paypal[.]com/signin', but clicking would take you to 198[.]51[.]100[.]23. Showing a trusted address while linking elsewhere is a classic phishing trick.
  4. MEDIUM SPF failed
    The server that delivered this was not authorized to send mail for mailer-notify[.]top. That is a common sign of a forged sender.
  5. MEDIUM Nothing proves this email really came from paypa1-secure[.]com
    No DMARC pass was recorded and neither SPF nor DKIM passed for a domain matching the From address.
  6. MEDIUM Authentication results contradict each other
    A lower Authentication-Results header (from 'paypal[.]com') claims SPF passed, but the receiving server's own check says fail. Fake 'pass' headers added by the sender are a known trick; trust the top one.
  7. MEDIUM Replies would go to a different address than the sender
    The email is from service@paypa1-secure[.]com, but pressing Reply sends your answer to paypal[.]resolution[.]team@gmail[.]com (a free personal mailbox). Scammers do this to receive replies while hiding behind a believable From address.
  8. MEDIUM The From and Return-Path domains do not match
    The email claims to be from paypa1-secure[.]com, but the hidden envelope sender (Return-Path) is mailer-notify[.]top, and authentication does not connect the two.
  9. MEDIUM A link in the message is suspicious: hxxps://bit[.]ly/3xPpL2k
    The link uses a URL shortener that hides the real destination. bit[.]ly is a link-shortening service. PhishLens does not open links, so the final site cannot be checked; phishers use shorteners for exactly that reason.
  10. LOW The first server in the delivery chain does not belong to the sender's domain
    The email claims to be from paypa1-secure[.]com but first entered the mail system at mail[.]paypal[.]com (IP 198[.]51[.]100[.]77). The receiving server could not confirm that name: the server's real network name is unknown, so the name it gave may be made up.

Links found in the message

  • hxxp://198[.]51[.]100[.]23:8080/paypal[.]com/webscr/login[.]php LIKELY PHISHING
    Shown as: “hxxps://www[.]paypal[.]com/signin”
  • hxxps://bit[.]ly/3xPpL2k SUSPICIOUS
    Shown as: “Restore access”

What to do

  • Do not click any links, open any attachments, or reply.
  • Do not enter passwords, codes, or payment details anywhere this email points you.
  • Report it: use your email app's 'Report phishing' button or forward it to your IT or security team, then delete it.
  • If you already clicked or typed a password, change that password on the real website (type the address yourself) and tell your IT team or bank.
